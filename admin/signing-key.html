Lists signing key

The app only trusts banners, dApps, tokens, the scam list and the emergency switches when they are signed with this key. The key is made here in your browser and is never sent anywhere.

This browser can't make the key. Please open this page in a recent Chrome or Safari.

  1. Tap Copy key.
  2. Open New secret on GitHub.
  3. In Name type LISTS_SIGNING_KEY. In Secret paste the key. Tap Add secret.
  4. Close this page. Don't save the key anywhere else and never send it in a chat.
  5. Tell Claude "signing key added". Claude finds the public half by itself.
