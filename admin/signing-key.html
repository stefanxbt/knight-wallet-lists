Lists signing key

The app only trusts lists that the robot signed with this key. You make it once. It is made right here on your device and is never sent anywhere.

  1. Press Make the key.
  2. Press Copy.
  3. Open New secret. Name: LISTS_SIGNING_KEY. Paste the key as the value and press Add secret.
  4. Open Sign the lists, press Run workflow, then the green Run workflow.
  5. Close this page. Don't save the key anywhere else.

Secret: anyone with this can sign fake lists. Only paste it into the GitHub secret.
